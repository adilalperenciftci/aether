- **`move` hands a buffer to an actor, and a use after it is a compile error
  (#2975).** `r ! Chunk { data: move buf }` sends the `ptr` buffer with no copy
  (the receiver gets the sender's data pointer) and leaves `buf` moved-from.
  The `Isolated[T]` move checker then refuses any later use of `buf` on any
  path that reaches it, and names the line of the move: a read, a second send,
  a free, a `defer` or a closure. It also refuses moving a borrowed parameter
  (declare it `@keep`), a capture, a field or element, and anything that is not
  a `ptr`. `move` is contextual, so `fs.move`, `mem.move` and a program's own
  `move()` still parse as calls. The same checker now handles `match`/`switch`
  arms and closures, and checks a `defer` where its block ends. Its message
  names the line of the move. The runtime does not free a moved buffer that
  its receiver drops, or one still queued when the receiver dies (#2974).
