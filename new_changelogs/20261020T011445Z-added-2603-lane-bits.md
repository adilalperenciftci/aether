- **A lane's bits, eight integer lanes, and the smallest or largest lane
  (#2603).** `bits4` / `bits8` read float lanes as integer lanes and
  `from_bits4` / `from_bits8` go back, bit for bit; with `mask8_and` /
  `mask8_or` they edit a float's bits, as an index kept in the low mantissa
  bits of a value is. `i32x8(...)` and `i32splat8` build eight integer
  lanes. `reduce_min4` / `reduce_max4` / `reduce_min8` / `reduce_max8`
  compare the lanes in one fixed order, so a tie or a NaN gives the same
  lane on every instruction set and in either form of `f32x8`.
