- **Moves between lanes: an 8x8 or 4x4 transpose in registers (#2550).**
  `std.lanes` had no way to move a value from one lane to another, so a
  structure-of-arrays gather built each `f32x8` from eight scalar loads and
  eight inserts. `unpacklo4` / `unpackhi4` / `pairs_lo4` / `pairs_hi4` and the
  eight-lane `unpacklo8` / `unpackhi8` / `pairs_lo8` / `pairs_hi8` /
  `halves_lo8` / `halves_hi8` are the six patterns a transpose is made of
  (Box3D's `b3TransposeW8`), each one instruction: 24 ymm shuffles for an
  8x8 transpose under `-mavx2`, the four-lane ones per half without it.
